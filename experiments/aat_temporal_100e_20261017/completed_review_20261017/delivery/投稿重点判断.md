# 投稿重点判断：主线选 C1

**有会议论文的投稿价值。按应用与实证研究写，当前不要包装成原创时序网络。**

统一独立 test（14,446帧，包含2,592背景帧），使用按 val AP50–95 选出的原生 best.pt：

| 方法 | AP50/% | AP50–95/% | 背景误报率/%（conf=0.25） |
|---|---:|---:|---:|
| YOLO11n | 62.70 | 34.49 | 11.38 |
| A1 全局 AAT | 60.91 | 33.59 | 14.12 |
| A2 序列配额 AAT | 62.05 | 33.88 | 14.74 |
| C1 时序输入 | **76.16** | **40.36** | 14.08 |
| C2 时序＋AAT | 75.66 | 38.84 | 20.22 |

这轮可以写清楚三件事：

1. **低成本时序输入在这套协议下有效。** 相同2.60M网络参数，C1 的 test AP50 比 YOLO11n 高13.46个百分点。热交叉组高19.68点；复杂动态背景组高18.57点。仅能说网络计算图不增加，缓存和输入构造仍须计时。
2. **AAT 的额外收益没有得到支持。** A1/A2 没有获得整体点估计收益；C2 也没有延续 val 上相对 C1 的微小优势。C2−C1 的序列 bootstrap 区间跨0，不能说 AAT 确定导致 AP 下降，更不能说已经获得协同增益。
3. **误报结论取决于阈值协议。** 固定0.25时 C1 背景误报增加；各模型仅在 val 选定约5%背景误报的阈值后原样用于 test，基线误报9.99%、正帧命中60.88%，C1 则为5.21%、70.73%。这是值得写的实际工作点分析，不是新发明的校准算法。

## 创新应怎样定位

三帧灰度堆叠已有明确前作：[Corsel 等，WACVW 2023](https://openaccess.thecvf.com/content/WACV2023W/RWS/html/Corsel_Exploiting_Temporal_Context_for_Tiny_Object_Detection_WACVW_2023_paper.html)，以及 [Temporal-YOLOv8，Sensors 2024](https://publications.tno.nl/publication/34643397/aHTTXwcv/leeuwen-2024-towards.pdf)。不能把“三帧装进三通道”单独列为首创。

CST 检测也不能再称完全空白：[2026-10-06预印本](https://arxiv.org/abs/2610.07705)已包含 CST 小无人机检测和框检测器对比，虽然研究问题、监督形式和评测指标与本项目不同。

本项目可写的贡献是**因果输入的任务适配、统一轻量模型比较、属性与误报的系统分析，以及可复核的真实证据**。单次种子结果不足以宣称领域 SOTA。

## 投稿前最少补什么

1. **同流程的重复当前帧训练对照。** 与 C1 使用同样的采样器、共享亮度增强、batch等设置；目前单帧基线的数据加载顺序和增强实现仍有区别。已有的“推理时抹掉历史”诊断不是这个训练对照。
2. **最接近前作的时序对照与时间间隔消融。** 不能只比较四个单帧 YOLO，就声称优于时序方法。对未来帧方法应注明其非因果输入条件。
3. **batch1完整输入到框的计时。** 包含历史缓存和输入构造；共享GPU批量推理耗时不等于边缘部署延迟。再做独立种子复验会更有说服力。

建议标题：**《因果时序输入在轻量红外反无人机检测中的有效性与误报分析》**。
