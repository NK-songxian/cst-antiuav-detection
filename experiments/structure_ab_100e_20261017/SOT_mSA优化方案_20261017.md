# SOT 与 mSA：可验证的创新候选，而非“完全空白”的承诺

2026-10-17；方案状态：尚未训练 SOT 模型；现有 A/B 是检测器，AP 不能换算成官方 SOT 的 mSA。

## 1. 先把任务与指标说准

CST 原任务是 SOT。应按标准协议给定初始目标框，按原始时间顺序运行，除规定初始化外不再使用真实框纠正，不在丢失后偷偷用 GT 重新初始化。目标出场、遮挡、重现帧全部保留。现有检测验证集每 5 帧抽样一次，9066 帧；完整 SOT 验证集是 40 个序列、45305 帧，二者不能直接与原论文表格对比。

本机官方工具包 commit：`bd92b984ff2c5271200497243b4ee6466d7cbdbe`。已读取 `experiments/cstanti_uav.py` 中 eval、not_exist 和逐序列平均的实际代码。

对有效 GT 帧，令 v=1 表示目标存在，b 表示预测框，空输出表示未检测到目标，则：

\[
SA_s=\frac1{T_s}\sum_t\left[v_t\,IoU(b_t,g_t)+(1-v_t)\,\mathbb{1}(b_t=\varnothing)\right],
\quad mSA=\frac1S\sum_s SA_s.
\]

目标存在、预测为空时 IoU 按 0 计。目标不存在时，官方代码通过 `len(pred)==0` 判定空输出；`[0,0,0,0]` 长度为 4，不能冒充空输出。不要把论文公式中的状态符号误解释成将任意连续“存在概率”直接加入离场得分。

每个序列先求均值，再平均各序列，不是把所有帧拼起来算一个均值。官方代码会跳过无效的可见 GT，本次完整 val 中未发现这类 GT。

## 2. 为什么不能只改“置信度阈值”

普通目标分数回答“这里像不像目标”；mSA 还要求框本身足够准确。小框偏几像素，IoU 就可能很差。即使目标分数一样，两个框的预期定位质量也可能不同。

因此，一个更贴合指标的候选是：

**同时预测“输出这个框能得到多少分”和“输出空结果能得到多少分”，再比较两者。**

这不是靠降低可见帧召回来虚增判空率。必须同时报告可见帧 IoU、可见帧检出率、离场帧误报、再捕获时间，检查得分变化来自哪里。

## 3. 主机制：状态收益预测头

冻结一个可复现的跟踪器，保留其候选框和基础特征。增加很小的两输出预测头：

\[
u_{box}(z_t)\approx E[v_t\,IoU(b_t,g_t)\mid z_t],
\qquad u_{empty}(z_t)\approx P(v_t=0\mid z_t).
\]

其中 z 只能含推理可得信息：目标模板与当前候选的相似度、响应图歧义、框尺寸与位置变化、定位特征、搜索覆盖情况；不能读测试属性或 GT 可见性。

训练标签来自训练序列的实际候选框：`y_box = v * IoU(pred_box, gt)`，`y_empty = 1-v`。候选框对标签计算停止梯度，第一阶段冻结原跟踪器，使用 MSE 等能估计条件均值的损失拟合两个收益。MLP 的设计预算 ≤0.02M 参数，实际增量以实现后统计为准。

推理时比较两个收益，决定输出候选框还是空结果。若存在概率为 p，且在目标存在条件下该框的预期 IoU 为 q，则单步规则为：

\[
u_{box}=pq,\quad u_{empty}=1-p,\quad
\text{输出框}\iff pq>1-p.
\]

这条规则是基于官方得分定义得到的单步期望收益比较，不是一个新统计定理，也不证明整段视频闭环最优。若预测质量、概率或数据分布失配，效果可能变差。

直观例子：两个候选都有 70% 的目标存在概率，一个框预计 IoU=0.8，另一个预计 IoU=0.2；相同的存在置信度并不代表相同的状态得分收益。

### 局部搜索的关键限制

“搜索裁剪区域里没找到目标”不等于“目标离开整幅图”。v 是全图目标存在状态。收益头必须接受训练中的真实“目标在图内、但出了当前搜索区”的样本及搜索覆盖信息；这些帧的 y_empty 仍是 0。无法辨别时，应允许触发原有的全图重检机制，而不能将搜索失败直接标成离场。

### 先隔离输出决策，再研究闭环

第一阶段只改变输出结果，原跟踪器的内部模板更新、搜索中心和重检调度保持原逻辑。这能区分“结果选择更合理”和“跟踪状态变好”。

第二阶段才单独研究判空后的模板冻结、重搜与再捕获。低质量时冻结模板、高置信时更新已有大量前作，不能仅靠这条规则声称新颖，也不能把纯输出阶段的收益称为减少了漂移。

## 4. 为什么有提升空间，也为什么不能预报 +5 点

完整 val：45305 帧，其中 6250 帧标记目标不存在；按序列平均，离场帧比例 **11.4677%**。各序列等权后，这个值不等于简单的 6250/45305。

对一个从不输出空结果的假想跟踪器，只把全部离场帧判断正确且不损伤可见帧，最多可补约 11.47 个 mSA 百分点。但实际长时跟踪器已经能正确判空其中一部分，因此剩余空间必须从真实基线预测中计算，不能把 11.47 点当作我们可得的提升。

给定已有轨迹框，可进一步计算一个仅用于诊断、依赖 GT 的上界：保持所有可见帧候选框不变，把所有离场输出改为空。该上界与当前 mSA 的差，才是“离场误判”可追回的分数。上界若小于 5 点，仅靠判空不可能在这些固定框上实现 +5；必须改善可见帧定位或丢失后的恢复。

另外，两个动作的 GT oracle 在可见帧总能选择非负 IoU 的框，因此其收益通常来自离场纠错。要获得稳定、实用的提升，需要模型既能区分离场，又不把热交叉、局部搜索失败和遮挡边界误当成离场。

## 5. 查新：哪些已有，候选差异在哪

| 前作 | 已有内容 | 与候选的关系 |
|---|---|---|
| ATOM，CVPR 2019 | 显式预测候选框与目标的重叠程度 | IoU 预测不是我们的原创 |
| IoU-Net，ECCV 2018 | 检测的定位质量估计 | 分类分数与定位质量有差异，不是新发现 |
| Cascade-DETR，ICCV 2023 | 用分类概率与预期 IoU 共同评分 | `p×q` 形式已有直接近邻，不能声称首次 |
| FocusTrack，2025 预印本 | 目标存在判断与搜索区域自适应 | 存在分支、调整搜索区已有前作 |
| MemLoTrack，2025 | 置信度驱动的记忆管理、红外反无人机跟踪 | 普通的高置信更新/低置信冻结已有前作 |

候选贡献定位：**把官方 mSA 对框输出与空输出的不同收益直接作为两个监督目标，并在不改变候选轨迹的对照中验证它是否优于充分调参的普通置信度判空。** 之后才评估闭环集成。

本次公开源检索未确认完全相同实现，但这不证明不存在。这个候选比“再加一层注意力”更贴合任务、便宜、易解释；目前不能认定“完全原创”。若只是调阈值有效、两个收益头没有额外收益，方法贡献应降级为校准研究。

## 6. 最小执行方案

### 阶段 A：先取得真正的 SOT 基线和错误分解

优先用一个有公开权重、当前环境能运行的跟踪器建立完整 val 轨迹。OSTrack-256 可作为现代跟踪基线候选；SiamDT 是反无人机专用强对照，但其官方环境依赖较旧，不直接在共享实例主环境降级安装。先在隔离环境验证兼容性，再决定可执行基线。

**这并不意味着 OSTrack 或 SiamDT 本身满足 2–3M 轻量预算。** 本阶段的结论是“小预测头能否优化 mSA”；若论文继续要求整体边缘轻量化，还必须在轻量跟踪器上复核并实报总参数与延迟。现有 B 只能作为后续检测/重检组件候选，不能因其 mAP50–95 较高就说它的 SOT mSA 已较高。

记录每帧候选框、分数、模板相似度、可见性预测、是否模板更新、是否全局搜索、耗时；按序列保存。统计：可见帧平均 IoU、离场帧误报、可见帧误判空、TC/Tiny 定位、离场/再进入边界、再捕获延迟。

### 阶段 B：小预测头与充分调参的判空对照

| 实验 | 唯一主要变化 | 回答的问题 |
|---|---|---|
| S0 | 原跟踪器 | 完整 SOT 基线是多少？ |
| S1 | 验证集调好的标量置信度阈值 | 仅靠阈值已经能提高多少？ |
| S2 | 相同输入和近似参数的存在预测头 | 是否只是“学会判空”带来的收益？ |
| S3 | 框收益＋空收益预测头 | 定位质量感知的决策是否有额外收益？ |

收益头只用训练序列的数据拟合；校准使用训练集内部按序列划出的 calibration 子集。官方 val 用于方案开发，测试集封存。所有基线获得匹配的调参预算。目标至少在另一个跟踪器上可迁移，再支持插件的普适性。

### 阶段 C：闭环是独立消融

S3 真有收益后，单独加入收益驱动的模板更新/重检策略，比较它与原策略；候选框轨迹改变时必须重新跑整段视频。不得在离线保存结果上改几个输出就宣称改进了搜索和恢复。

### 验收与止损

- 总目标可设为相对匹配 SOT 基线 **+5 个 mSA 百分点**，这是挑战目标，尚无实验支持。
- S3 必须超过 S1/S2，才能把贡献归因于状态收益建模；只超过未经调参的 S0 不够。
- 可见帧检出率、平均 IoU、再捕获延迟同时报告；不能靠长期输出空结果或延迟承认目标重现来涨分。
- 正式比较用相同完整序列、相同初始化、同数据训练条件。多种子估计训练随机性；序列为 bootstrap 单位。
- 若固定轨迹上的 oracle 剩余空间很小，或 S3 没有稳定超过充分校准的阈值对照，停止把它当主方法，回到定位/重检的真实瓶颈。

## 7. 可解释性图

1. 一段真实视频的候选框、`u_box`、`u_empty`、最终输出与 GT 可见性。GT 只用于事后分析，曲线显示决策切换时间。
2. 相同存在分数下，定位好/定位差两个样本，显示收益预测为何不同。
3. 可见定位贡献与离场判空贡献的 mSA 分解；每序列一个点，展示改善是否只靠少数离场较长视频。
4. 热交叉、离场、重新进入各一段成功与失败例，显示是否错误冻结、是否迟迟不重新输出框。
